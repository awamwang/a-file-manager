# Work Groups / Projects 路径卡片与用法提示

- Members / workspace links / 运行时标签改为 Fluent `path-card`；点击 `openOrFocusNavigatorTab` 进导航器。
- 页头 `usageHint`（en/zh-CN/ja/de/fr）：WG=批量打开关联/同类型工作标签；Project=整体进度与共享知识，编码时绑定 WG 共同编辑。
