# 统一搜索面板（Ctrl+Shift+P）

命令面板原本只列应用命令：文件搜索在 Discovery，项目/工作组/工具各自只有导航命令。用户需要一个入口完成“找文件、打开文件、跑工具”。

决定把 Ctrl+Shift+P 升级为统一的搜索面板：单一输入框 + 搜索源注册表 + 分类分组；范围可多选组合并跨会话持久化，默认「全部」；每一行显式展示类型标签。结果主动作按源定义：命令执行；文件按 `core.fileDoubleClickAction` 打开（Ctrl+Enter 在资源管理器定位）；项目跳 `/projects?slug=<slug>` 仅聚焦、不激活；工作组静默切换；工具/能力默认跳转并预选，可按 `command-palette.json` 覆盖为调用非破坏性能力。文件组限 8 条并通过 Discovery 查看完整结果；工具/能力由网关拉取并缓存 5 分钟，离线时只显示状态行；Pack 可在清单声明静态条目，统一归入「扩展」。

## Consequences

面板不执行有副作用的批量操作：破坏性能力必须进入工具运行时确认；新增搜索源实现统一接口而不是新增快捷键；Discovery 与 Ctrl+Shift+F 保留为完整文件结果入口，面板只做 Top N。
