# 资源管理器基本功能清单与对照

盘点日期：2026-11-06。对照对象是当前仓库里的 Navigator / 文件操作实现，不是旧的 `docs/a-file-manager-feature-map.md`（那份地图仍写着缺 F5、新建文件、预览、属性、压缩，和现在的代码不符）。

范围只收「打开一个文件夹就能用」的基本能力。工作组、项目、Discovery 全机搜索、Providers、扩展、双栏、命令面板、用 IDE / 终端打开，算本产品多出来的能力，不记成资源管理器缺口。

## 资源管理器基本功能（整合）

1. **窗口骨架**  
   标签；后退 / 前进 / 向上 / 刷新；地址栏（点路径段跳转，或整段改成可输入）；当前文件夹搜索框；命令栏（新建、剪切、复制、粘贴、重命名、共享、删除、排序、视图）；左侧导航窗格；中间内容区；可选的预览窗格和详细信息窗格；底部状态栏。

2. **去哪里**  
   快速访问（固定文件夹 + 常用 + 最近）；已知文件夹（桌面、文档、下载、图片、音乐、视频）；此电脑（磁盘）；网络位置 / UNC；回收站；库和 OneDrive 可显示。地址栏接受本机路径和 `\\server\share`。历史：后退、前进、向上一级。

3. **内容怎么排**  
   特大 / 大 / 中 / 小图标、列表、详细信息、平铺、内容；紧凑视图。详细信息至少有名称、修改日期、类型、大小。点列头排序。可分组。可调列宽。默认不显示隐藏项，可打开。图标大小可用 Ctrl+滚轮调。

4. **选中与打开**  
   单击选中；Ctrl 加减选；Shift 选范围；Ctrl+A 全选；拖出矩形多选；方向键移动。双击或 Enter：文件夹进入，文件用默认程序打开。可「打开方式」。

5. **改文件**  
   新建文件夹，以及按已安装程序新建空文件。复制、剪切、粘贴。同名时询问替换、跳过或保留两者。拖放：同一驱动器默认移动，不同驱动器默认复制；按住 Ctrl 强制复制，Shift 强制移动，Alt 建快捷方式。重命名时文件只选中主名、不选扩展名；多选重命名会自动加序号。Delete 进回收站；Shift+Delete 永久删除。可撤销上一次复制 / 移动 / 重命名 / 删除。属性里看大小、时间、只读 / 隐藏，并能改其中一部分。压缩成 ZIP，或解压到指定目录；ZIP 也可以当文件夹打开。

6. **查找**  
   搜索框搜的是当前文件夹及其子文件夹，可带 `*.pdf`、日期、类型等条件。范围不是「只过滤已经列出来的这一层名字」。

7. **状态与其它**  
   状态栏给出项目数、选中项大小、可用空间。可复制路径。可共享。导航窗格可以展开文件夹树。

## 和当前实现的对照

图例：**对齐** 行为接近；**部分** 有入口但比基线窄；**缺失** 没有这条能力；**不一致** 有实现，但语义和资源管理器不同，需要单独决定。

### 窗口与导航

| 功能 | 资源管理器 | 当前实现 | 结论 |
| --- | --- | --- | --- |
| 后退 / 前进 / 向上 | Alt+← / Alt+→ / Alt+↑，以及按钮 | 同样三组快捷键，另有 Ctrl+Alt+←/→ | 对齐 |
| 刷新 | F5 | F5 → 重新列目录 | 对齐 |
| 地址栏 | 面包屑 + 输入路径；Ctrl+L、Alt+D、F4 | 面包屑可点；Ctrl+L / Alt+D / F4 聚焦；提交时展开 `%VAR%` | 对齐 |
| UNC | 地址栏可进 `\\server\share` | `path_guard` 接受 UNC，地址栏能导航过去 | 对齐（没有「网络」这个位置入口） |
| 标签 | 每个窗口一组普通文件夹标签。Ctrl+T 新建，Ctrl+W 关闭，Ctrl+Tab 下一个，Ctrl+数字跳到第 n 个 | 标签是工作组 Open State：可分组、随工作组保存。Ctrl+T 新建。关闭靠标签上的按钮。Ctrl+Tab 切的是标签组 | 不一致 |
| 新窗口 | Ctrl+N | 无 | 缺失 |
| 导航窗格 | 常驻树：快速访问、此电脑、磁盘、可展开子文件夹 | 左侧是产品页（导航、工作组、项目、Discovery、Providers、扩展、设置）。磁盘、已知文件夹、最近、收藏在 Guide 页（`afm://guide`）的卡片上，不是树 | 不一致 |
| 已知文件夹与磁盘 | 导航窗格里一直在 | Guide 卡片：主目录、桌面、文档、下载、图片、音乐、视频、盘符 | 部分 |
| 快速访问 / 固定 | 固定到快速访问，可取消固定 | 收藏星标 + 访问统计里的「最近」，都在 Guide 上。另有收藏的系统钩子开关 | 不一致 |
| 回收站位置 | 可在导航里打开，并还原 | Guide / 侧栏 / Places 可进 `afm://recycle-bin`，双击或右键还原 | 对齐 |
| 网络位置、库、OneDrive | 导航窗格入口 | Guide / 文件夹树：OneDrive、库、映射的网络位置；UNC 仍走地址栏 | 对齐 |
| 焦点循环 | F6 在标签 / 导航 / 内容 / 状态栏之间移动 | F6 / Shift+F6 循环；内容区方向键移动选中 | 对齐 |

### 搜索与状态栏

| 功能 | 资源管理器 | 当前实现 | 结论 |
| --- | --- | --- | --- |
| 当前文件夹搜索 | 搜索框递归当前目录和子目录，支持通配符和属性条件。Ctrl+E / Ctrl+F / F3 | 地址栏旁输入框只过滤**已经列出的这一层**的名称或路径。不进入子文件夹 | 不一致 |
| 全机搜索 | 主页搜索可覆盖本机和已登录的云 | Discovery 走 Everything（Ctrl+Shift+F 在非导航页）。这是额外能力，不是当前文件夹搜索 | 超出基线 |
| Ctrl+Shift+F | 资源管理器不用这个键做搜索 | 快捷键 id 是 `discovery.globalSearch`。在导航页却只聚焦本层过滤；在其它页才打开 Discovery。`docs/a-file-manager-search-status.md` 仍写「导航页没有本页过滤、Ctrl+Shift+F 进 Discovery」 | 不一致（文档、快捷键名字、实际行为三处对不上） |
| 状态栏 | 项目数、选中大小、可用空间，以及视图按钮 | 文件夹/文件数 + 选中项大小 + 卷剩余空间；右侧仍为健康状态 | 对齐 |
| 预览 | Alt+P 预览窗格；Alt+Shift+P 详细信息窗格 | 内置预览栏（图片、文本）+ Space 调外部 Peek / QuickLook。属性是另一块只读侧栏。无 Alt+P | 部分，触发方式不同 |

## 标签（已定）

不新增一套「普通标签」。导航页现有那一排继续是标签组。

**Pin**

- 增加 pin 标签组的动作。
- 双击标签切换 pin / 取消 pin。
- 已 pin 的标签彼此相对位置不变。
- 切换工作组时，pin 住的标签留在标签条上；未 pin 的标签换成目标工作组保存的 Open State。

**快捷键（补齐，不新做标签模型）**

- Ctrl+W 关闭当前标签。
- Ctrl+数字 跳到对应标签。

**默认工作组**

- 已有 `default-work-group`（`is_default`，删除会被拒绝）。界面写成「默认工作组」。
- 不可删除，也不能改成普通工作组。
- 给没有专门工作组时的临时浏览用。数据里的显示名目前仍是英文 `Default`，要对齐成「默认工作组」。
