# 核心概念（Core Concepts）

面向使用者的三个核心概念——工作组、项目、AI 功能——的权威定义。界面说明、上手提示、帮助文档中出现这三个概念时，一律以本文件的定义为准；多上下文索引见 [GLOSSARY-MAP.md](../GLOSSARY-MAP.md)。

## Language

**工作组（Work Group）**：
把同一件事相关的文件夹聚在一起。它是位置的集合，不移动或复制磁盘上的文件。
_Avoid_: 标签带、会话组、项目（工作组不创建工作目录）

**项目（Project）**：
工作组的升级形式。它会创建独立的工作目录，并建立面向 AI 开发的基础结构（CONTEXT、任务与成果等）。
_Avoid_: 任务列表、待办工具、工作组（项目是工作组的升级，不是同义词）

**AI 功能（AI Features）**：
提供 AI 开发相关的 Agent 管理，以及 MCP / Skills 等工具管理。为可选能力，仅主线版提供；精简版不显示。
_Avoid_: AI 助手、AI 插件、AI 工具箱

**收藏（Favorites）**：
常用位置的快捷入口。只作为「浏览文件」里的一个入口存在，不单独设帮助条目、上手提示或引导教学。
_Avoid_: 独立导引、收藏教程

## 编排规则

三个概念的「是什么」以本文件为准，并按 [帮助与导引](./glossary-help-guidance.md) 的三层规则落到各处：

- **界面描述**（视图页 meta / usageHint）：用一句话给出本文件的核心定义，不展开操作步骤。
- **上手提示**（`help.entries.*.hint`）：只讲「是什么」，文案与核心定义一致。
- **帮助文档**（`src/help/content/*.md`）：在「它是什么」沿用核心定义，其余小节讲全貌与操作。
- **引导教学**：只讲「怎么做」，不复述概念定义。
- **i18n**：六个语言（en / zh-CN / zh-TW / ja / de / fr）表达同一定义，key 保持一致。

改动本文件定义时，须同步检查 `src/i18n/locales/*.json` 与 `src/help/content/*.md`，并运行相应门控。
