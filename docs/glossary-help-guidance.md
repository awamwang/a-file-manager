# 帮助与导引（Help & Guidance）

面向使用者的应用内帮助体系：可随时查阅的静态说明、首次进入的短提示、以及「点这里、完成那一步」的操作教学；三层共用一份声明式导引定义，供后续新特性沿用。多上下文索引见 [GLOSSARY-MAP.md](../GLOSSARY-MAP.md)。

## Language

**帮助与导引（Help & Guidance）**：
应用内帮助体系的总称，含帮助文档、上手提示、引导教学三层。
_Avoid_: 帮助中心、用户手册（外置文档）、Guide（已被起始页占用）、Help（泛指）

**帮助文档（Help Article）**：
按功能组织、可随时查阅的静态说明；回答「这个功能是什么、怎么用」。
_Avoid_: 教程、用户手册、文档页、Guide

**上手提示（Getting-started Hint）**：
首次进入某功能时出现的一句话定位说明，告诉用户这里是什么；气泡内含一个「引导我试一试」入口，只有用户主动点击才触发教学。不要求用户操作，也不会因为「没看过」而自动播放教学。
_Avoid_: 引导教学、Tour、提示气泡、Tooltip（那是快捷键悬停提示）

**引导教学（Guided Tour）**：
聚光灯式的一步一步操作演示：高亮目标元素、说明该点哪里；关键步骤须用户真实点击后才进入下一步，可跳过、可重播。仅由用户主动请求触发——上手提示的「试一试」按钮、功能页「?」深链、帮助中枢重播；不再基于是否已看过自动播放。
_Avoid_: 教程、Walkthrough、新手引导、Onboarding、Guide

**导引注册表（Guidance Registry）**：
三层内容共用的唯一声明式定义源：每条记录绑定功能视图、帮助文档、上手提示 key 与教学步骤，并声明适用条件；新特性通过登记条目接入，不另起体系。
_Avoid_: 教学配置、导引脚本、帮助中心配置

**重播（Replay）**：
按用户请求再放一遍某条引导教学，不改动「已看过」进度；用户忘记操作时走这条路。
_Avoid_: 重置、重新初始化、回放录像

**重置上手进度（Reset Onboarding Progress）**：
只清除「哪些提示与教学已看过」的本地标记，使上手提示和教学能被用户再次请求；不触碰用户数据或设置。
_Avoid_: 恢复出厂设置、重置应用、清空设置

## 编排规则：三层不互相复述

- 帮助文档讲全貌与细节：完整说明功能是什么、能做什么、边界与注意事项。
- 上手提示只讲「是什么」：一句话定位当前位置，不写「点击哪里」「如何操作」。
- 引导教学只讲「怎么做」：直接进入操作步，开场不复述功能概念。
- 同一句文案只在一个层级出现；新增或改动导引内容时，逐层检查是否重复。
