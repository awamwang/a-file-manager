# AI 功能（主线版才有）

## 它是什么

AI 功能提供 AI 开发相关的 Agent 管理，以及 MCP / Skills 等工具管理。它是可选能力：仅主线版提供，精简版不会显示这一项，也不会要求你配置它。

## 怎么打开

在左侧找到「AI」并点击。若你的版本没有这一项，说明当前是精简版。

## 能做什么

- 发现并启用 Agent Target，配置全局与项目相对的 Skills 目录、MCP 路径。
- 维护中央仓库中的 MCP 目录条目与 Library Skill，并部署到已启用的 Agent。
- 在需要时关闭或清理不再使用的配置。

## 常见操作

1. **查看能力**：进入页面后，左侧列出不同分区，右侧显示当前分区的说明与设置。
2. **切换分区**：点击左侧的分区名称；右侧内容会随之更新。
3. **检查连接**：如果某项能力依赖外部服务，请先确认服务地址可用。
4. **接入工具**：在工具目录中登记你需要的条目，再回到原功能中使用。

> 小提示：AI 功能按需使用。不使用它时，完全可以把它当作不存在；工作组与项目等核心功能不依赖它。
