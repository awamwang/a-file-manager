# 浏览文件（此电脑）

## 它是什么

浏览文件是你日常使用 A File Manager 的起点。它把电脑上的文件夹和文件按你熟悉的树形结构展示出来，左侧是位置与文件夹树，中间是文件列表，右侧可以打开预览和详细信息。

## 怎么打开

- 启动应用后默认进入浏览文件。
- 任何时候都可以点击左侧的「此电脑」回到它。
- 点击顶部的路径栏可以直接输入一个文件夹地址并跳转。

## 能做什么

- 打开文件夹、进入上一级、在位置之间来回切换。
- 按名称、类型、大小或修改时间给文件排序；切换列表、详细信息、图标等显示方式。
- 选中文件后查看预览、复制路径、重命名、移动或删除。
- 用标签页同时打开多个位置，需要时并排比较两个文件夹。
- 显示隐藏文件，方便处理以点开头的配置项目。

## 常见操作

1. **找到文件**：在文件列表中单击选中，双击打开；文件夹会进入下一层。
2. **回到常用位置**：点击左上角的星标，打开「最近访问」和「收藏」，一键回到常用文件夹。
3. **切换显示方式**：使用工具栏的视图按钮在列表和图标之间切换；在详细信息视图中点击列标题即可排序。
4. **并排比较**：打开双栏模式，左右各选一个文件夹，然后拖动文件完成移动或复制。
5. **收藏文件夹**：在星标菜单中把当前位置加入收藏，下次直接点开。
