# 统一搜索

## 它是什么

统一搜索让你在一个输入框里查找文件、文件夹、收藏、项目和其他内容。它把分散在不同位置的入口合并起来，不用先猜「这个东西到底存在哪里」。

## 怎么打开

- 点击窗口右上角的搜索按钮。
- 或按界面上显示的快捷键（在按钮提示中可以看到当前键盘组合）。

## 能做什么

- 输入关键词，立即看到匹配的结果并按来源分组。
- 用方向键在结果间移动，按回车打开选中的条目。
- 通过来源标签缩小范围，例如只看文件、只看收藏或只看知识内容。
- 搜索 chords / 命令，直接触发应用内的操作。

## 常见操作

1. **开始搜索**：打开面板后直接输入名字的一部分，不需要完整路径。
2. **切换来源**：点击输入框下方的来源标签，或用标签上提示的组合键快速开关。
3. **打开结果**：用方向键选中后按回车；想看全部结果时选择分组末尾的「查看全部」。
4. **关闭面板**：按 Esc，或点击面板外的空白区域。

> 小提示：搜索范围是你可以控制的。如果某类结果一直干扰你，把对应来源标签关掉即可。
