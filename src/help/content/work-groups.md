# 工作组

## 它是什么

工作组把和某件事有关的文件夹聚在一起。比如「客户 A」可以包含一个资料文件夹、一个合同文件夹和一个交付文件夹；切换工作组时，你会立刻回到这一组工作现场。

## 怎么打开

点击左侧的「工作组」，进入工作组页面。页面左边是工作组列表，右边是选中工作组的详情。

## 能做什么

- 新建、重命名、删除工作组，拖动列表项调整顺序。
- 给工作组添加多个文件夹路径，作为它的成员。
- 在详情中打开某个成员文件夹，或把成员提升为新的工作组。
- 使用默认工作组收纳还没有归类的位置。

## 常见操作

1. **新建一个工作组**：在左下角的输入框中起一个名字，点击创建。
2. **添加成员**：在右侧详情页选择添加文件夹，选择你经常一起使用的位置。
3. **切换工作组**：点击左侧列表中的任意一项；当前激活的工作组会被高亮。
4. **调整顺序**：拖动左侧列表项到想要的位置，松开即可保存。
5. **删除工作组**：用列表项右侧的「更多」菜单选择删除；删除工作组不会删除你磁盘上的文件。

> 小提示：工作组只是位置的集合，它不会移动或复制你的文件。
